# OldPad

给家里老人用的 **离线平板**：打开就是超大的格子，点一下就能看电视剧、看照片、下五子棋。
不联网、不注册、不上传，所有内容都留在平板本地。

> 目标设备：Android 7.0+ 的旧平板 / 旧手机（minSdk 24）
> 包名：`com.oldpad.app`　当前版本：`1.0`

## 功能

- **大格子首页**：每个格子都是一个视频剧集、一组照片或一个游戏，字大、图大、触摸区域大。
- **最近使用**：首页最前面 3 格自动显示最近打开过的内容（视频 / 相册 / 游戏）。
- **一键播放**：进入剧集点任意一集即可播放；一集放完自动播下一集。
- **断点续播**：没看完的电视剧，下次点开会从上次的位置继续；剧集列表会显示“已看 45%”。
- **老人友好的播放器**：超大播放/暂停按钮、后退 30 秒、前进 30 秒、一键慢速、大音量按钮。
- **防误触**：播放时控制栏自动隐藏；退出需要二次确认；还有“锁定”模式，锁定后长按屏幕 2 秒才能解锁。
- **字幕**：自动加载视频旁边的同名 `.srt` / `.ass` / `.ssa` / `.vtt` 字幕，播放器里大字幕一键开关，字幕大小可在设置里调。
- **相册**：按文件夹自动分组成“孙女”“旅游”等相册，全屏看图、上一张/下一张、自动播放。
- **离线小游戏**：模块化游戏框架，已内置五子棋；后续可继续加象棋、麻将等（见[游戏](#游戏可扩展)）。
- **开机自启 / 桌面模式**：可设置开机自动进入；也可以直接把它当成平板的“桌面”。
- **全程离线**：没有网络权限，不上传任何数据，也不含广告。

## 第一次使用

1. 打开 OldPad，系统会询问“允许读取照片和视频”，选择 **允许**。
   - Android 13+ 会分别询问“照片和视频”，两个都允许。
   - Android 14 如果只选“选中的照片”，相册只会显示你选的那几张。
2. 让家人把视频和照片拷进平板（见下面两节）。
3. 回到首页会自动刷新；如果没有，点首页顶部的提示条或“设置 → 重新扫描”。

> 即使不授权，五子棋等小游戏也能正常玩；授权后才会出现视频和相册。

## 视频怎么放

把视频复制到平板的 **Movies** 文件夹。规则很简单：

| 目录结构 | 首页显示 |
| --- | --- |
| `Movies/西游记/第01集.mp4`<br>`Movies/西游记/第02集.mp4` | 一个“西游记”大格子，点进去是剧集列表 |
| `Movies/世界杯/巴西vs德国.mp4` | 一个“巴西vs德国”大格子，点一下直接播放 |
| `Movies/比赛1.mp4`<br>`Movies/比赛2.mp4` | 直接放在 Movies 根目录的视频，每个视频单独一格 |

- 一个**子文件夹** = 一部电视剧 / 一组视频。
- 直接放在 `Movies`、`DCIM`、`Download` 根目录的视频 = 零散视频，各自单独一格。
- 文件名不用改；剧集排序会识别“第1集 / 第10集 / 01 / 02”里的数字。

### 关于“解码不卡、不花屏”

OldPad 使用系统自带的硬件解码（ExoPlayer + MediaCodec），能不能播主要看平板本身支持什么格式。给老人准备内容时建议：

- **最稳**：`MP4` 容器 + `H.264 (AVC)` 视频 + `AAC` 音频，1080p 以内。
- 老平板不要用 `HEVC/H.265`、`AV1`、10bit、4K，容易出现有声无画或卡顿。
- 如果原片是 MKV/HEVC，可以先转成 H.264 MP4（电脑上有 ffmpeg 的话）：

```bash
ffmpeg -i 原视频.mkv -c:v libx264 -profile:v high -level 4.0 \
  -c:a aac -b:a 128k -movflags +faststart 第01集.mp4
```

- 网络下载的 `.ts`、`.rmvb` 等格式兼容性较差，建议先转换。

## 照片怎么放

照片放在 **Pictures** 文件夹，按文件夹分组：

```
Pictures/孙女/001.jpg
Pictures/孙女/002.jpg
Pictures/旅游/IMG_0001.jpg
```

- 每个子文件夹 = 一个相册格子（例如“孙女”）。
- 首页还会自动生成一个“全部照片”格子。
- 支持 JPG / PNG / WebP 等系统支持的图片格式；HEIC 在老设备上可能无法显示。

## 首页与管理后台

首页完全由“格子”组成：

1. **最前面最多 3 格**：最近打开过的视频、相册或游戏（带“最近”角标）。
2. **后面**：按“管理首页格子”里的顺序排列。

### 管理首页格子（给家人用）

打开 **设置 → 管理首页格子**：

- **↑ / ↓**：调整顺序。
- **开关**：关闭后不在首页显示（内容不会被删除）。
- **恢复自动排序**：清空自定义顺序。
- 新加的视频 / 照片 / 游戏会自动出现在末尾，不会打乱已有顺序。

首页格子数量建议控制在 8～12 个，太多老人反而不好找。

## 播放器怎么用

进入播放后：

| 操作 | 效果 |
| --- | --- |
| 轻点屏幕 | 显示 / 隐藏按钮 |
| 中间大按钮 | 播放 / 暂停 |
| 慢速 | 正常 → 0.75 倍 → 0.5 倍 → 正常，循环切换（会记住） |
| ⏪30 / 30⏩ | 后退 / 前进 30 秒 |
| 音量－ / 音量＋ | 调大调小声音，屏幕会显示当前音量 |
| 字幕开 / 字幕关 | 开关字幕（没有字幕文件时不显示这个按钮） |
| 锁定 | 隐藏所有按钮并锁定触摸，防止老人擦屏幕误触 |
| 返回 | 弹出“要退出观看吗？”，确认后才退出 |

- 锁定后：**长按屏幕任意位置 2 秒** 解锁。
- 一集播完会自动播下一集；全部播完会停在最后一集。
- 播放进度会自动保存，下次从上次的位置继续。
- 播放中屏幕不会自动熄灭（可在设置里关闭）。

## 字幕

支持外挂字幕，完全离线：

```
Movies/西游记/第01集.mp4
Movies/西游记/第01集.srt
Movies/西游记/第01集.chs.ass
Movies/西游记/第01集.zh-CN.vtt
```

- 支持 `.srt`、`.ass`、`.ssa`、`.vtt`。
- 文件名必须和视频同名，可以加 `.chs`、`.cht`、`.zh`、`.en` 等语言后缀。
- 默认优先简体中文，然后其他中文字幕，再到英文字幕。
- 自动识别 UTF-8 / GBK / UTF-16 编码并转成 UTF-8，老字幕不会乱码。
- 字幕大小：**设置 → 字幕大小 → 大 / 更大 / 最大**。

### Android 11+ 需要额外授权

从 Android 11 开始，系统默认不允许应用读取视频旁边的 `.srt` 文件。
如果字幕不显示，请到 **设置 → 允许读取字幕文件（所有文件访问）**，在系统页面里打开开关。
这是可选权限：不开启也能正常看视频，只是没有外挂字幕。

> 注意：部分品牌把这个开关叫“所有文件访问权限”或“管理所有文件”。

## 相册

- 首页点相册格子 → 照片墙（3～6 列，随屏幕宽度变化）。
- 点任意照片 → 全屏查看。
- 底部三个大按钮：**上一张 / 自动播放 / 下一张**。
- 自动播放每 4 秒换一张，循环播放，适合当电子相框。
- 查看照片时屏幕常亮。

## 游戏（可扩展）

当前内置：**五子棋**（老人执黑先手，电脑执白，先连成五子获胜）。

游戏采用模块化设计，加新游戏不需要改首页、设置或排序逻辑。

### 加 HTML5 开源游戏（最快）

把游戏放进：

```
app/src/main/assets/games/你的游戏/
├── game.json
└── index.html
```

`game.json`：

```json
{
  "title": "象棋",
  "subtitle": "点棋子走棋",
  "emoji": "♟"
}
```

要求：

- 纯离线：所有 JS/CSS/图片放在同一目录，**不能依赖 CDN**。
- 入口必须叫 `index.html`。
- 应用里的 WebView 已禁止联网，不会偷偷下载东西。
- 重新打包 APK 后，游戏会自动出现在首页和管理页。

### 加原生游戏

1. 实现 `com.oldpad.app.game.GameModule`（返回一个自定义 `View`）；
2. 实现 `com.oldpad.app.game.GameProvider`；
3. 在 `GameRegistry.nativeProviders` 里加一行。

参考 `app/src/main/java/com/oldpad/app/game/gomoku/`。

更多说明见 [`app/src/main/assets/games/README.md`](app/src/main/assets/games/README.md)。

## 开机自启与桌面模式

### 开机自动打开

**设置 → 开机自动打开** 打开（默认已开）。

Android 10 以后系统对“后台启动界面”有限制，不同品牌还需要额外允许：

| 品牌 | 需要做的事 |
| --- | --- |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → OldPad → 自启动；省电策略选“无限制” |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → OldPad → 关闭“自动管理”，允许自启动、关联启动、后台活动 |
| OPPO / 一加 / realme | 设置 → 应用管理 → OldPad → 允许自启动、允许后台活动 |
| vivo | 设置 → 应用与权限 → 权限管理 → 自启动 → 允许 |
| 三星 | 电池 → 后台使用限制 → 把 OldPad 加入“不休眠的应用” |

另外建议点一下 **设置 → 关闭电池优化**，避免系统过一会儿把应用杀掉。

### 设为桌面（最可靠）

**设置 → 设为桌面** 打开后，按提示把 OldPad 选为默认桌面。
这样开机后一定会直接进入 OldPad，也能避免大部分“开机自启被拦截”的问题。

想恢复原来的桌面：系统设置 → 应用 → 默认应用 → 桌面，改回原桌面即可。

## 自己编译

环境：

- JDK 17
- Android SDK Platform 34、Build-Tools 34.0.0
- 无需 Android Studio，命令行即可

```bash
# 1. 指向本机 Android SDK
echo "sdk.dir=$HOME/Android/Sdk" > local.properties

# 2. 编译 Debug APK
./gradlew assembleDebug

# 3. 跑冒烟测试（首页/设置/相册/播放器/游戏/搜索 + 数据逻辑）
./gradlew testDebugUnitTest

# 产物
# app/build/outputs/apk/debug/app-debug.apk
```

国内网络如果下载依赖慢，可以在 `settings.gradle.kts` 的仓库里加镜像（Google Maven 不能省）。

### 打正式包（可选）

```bash
keytool -genkeypair -v -keystore oldpad.jks -alias oldpad \
  -keyalg RSA -keysize 2048 -validity 10000

# 在 app/build.gradle.kts 里配置 signingConfigs，然后
./gradlew assembleRelease
```

`*.jks` 和 `keystore.properties` 已经在 `.gitignore` 里，不会误传。

## 已知限制与 FAQ

**Q：为什么有些视频有声无画？**
A：平板硬件不支持该编码（常见于 HEVC / AV1 / 10bit）。转成 H.264 MP4 即可，见[视频怎么放](#视频怎么放)。

**Q：为什么语音搜索说“没有语音识别”？**
A：语音识别依赖系统里的识别服务。很多国产平板没有预装，或者没有下载离线中文包。此时请用屏幕键盘输入剧名；模糊搜索不要求字完全连续，例如输入“西游 三打”也能找到。

**Q：字幕不显示？**
A：先确认文件名和视频同名；Android 11+ 还需要在设置里开启“所有文件访问”。如果字幕是 `PGS` 图形字幕（`.sup`），当前不支持。

**Q：首页只有五子棋，没有视频？**
A：检查是否允许了照片/视频权限；再确认视频在 Movies 文件夹，然后“设置 → 重新扫描”。

**Q：开机没有自动打开？**
A：国产系统限制较多，按[开机自启](#开机自启与桌面模式)里的品牌表格设置；最稳的是开启“设为桌面”。

**Q：能不能联网看视频 / 在线更新？**
A：第一版定位就是完全离线：没有网络权限，视频和照片都从本地读取。

**Q：怎么彻底退出应用？**
A：播放器里点返回并确认退出；在首页按系统返回会退出应用（如果设成了桌面，会回到系统桌面选择）。

## 隐私

- 无网络权限（`INTERNET` 未声明），不会联网。
- 不包含统计、广告、账号、云同步。
- 所有播放进度、排序、设置都保存在本机 `SharedPreferences`。
- 卸载应用会清除这些本地设置，但不会删除视频和照片。
